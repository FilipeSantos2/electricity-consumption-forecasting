# Energy Forecast

An electricity consumption forecasting application built with Python and PyTorch.

## Objectives

- Explore and process historical electricity consumption data.
- Implement and evaluate forecasting baselines.
- Develop neural network forecasting models using PyTorch.
- Expose predictions through a REST API.
- Store observations and predictions in PostgreSQL.
- Visualise results through a Streamlit dashboard.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- PyTorch
- FastAPI
- PostgreSQL
- Streamlit
- Docker

## Project Structure

- 'data'/: Raw and processed datasets.
- 'notebooks'/: Data exploration and experimentation.
- 'src'/: Application and machine learning code.
- 'tests'/: Automated tests.

## Dataset
